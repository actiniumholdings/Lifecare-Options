# Lifecare Options — Website Redesign Design Spec

**Date:** 2026-04-17
**Owner:** Clint Ives (Director of Operations, Actinium Healthcare Holdings)
**Status:** Ready for implementation planning

---

## 1. Context

Lifecare Options (LCO) is one of four Medicare-certified home-health agencies under Actinium Healthcare Holdings, serving Katy, Fort Bend, and Harris counties since 2008. The current site (`mylifecareoptions.com`) is a sparse Wix template with a small dated logo, generic stock imagery, minimal copy, and no functional CTAs. It fails to communicate the agency's credentials, services, or trustworthiness.

This spec defines a full rebuild — new content, new brand system, new technical stack — targeting the aesthetic of the Dribbble reference at [dribbble.com/shots/27130133](https://dribbble.com/shots/27130133-Website-redesign-for-a-Accurate-Care-Home-Health).

## 2. Goals & audiences

**Primary job-to-be-done:** Help families researching home health for an aging parent build trust with LCO and call (or submit a request).

**Audience priority:**
1. **Families / adult children** of aging patients (primary)
2. **Referral sources** — hospital case managers, physicians, SNFs
3. **Patients** being discharged and needing home health
4. **Recruits** — RNs, LVNs, HHAs, caregivers

**Success criteria (qualitative, v1):**
- Looks like a premium modern healthcare brand, not a Wix template
- Every page has a clear primary CTA (Request Care / Call / Submit Referral)
- Loads fast, works well on mobile, passes accessibility basics
- Content is credible and specific — not generic home-health boilerplate

## 3. Scope

**In scope:**
- 9 top-level pages (Home, About, Services, Service Area, Insurance, For Referral Sources, FAQ, Careers, Contact) + 6 service sub-pages + a Request Care form page = 16 routes total
- Request Care multi-step form → email delivery
- Downloadable referral fax form (PDF)
- Interactive service-area map
- Brand system: palette, typography, component library, logo lockup
- 8 AI-generated watercolor illustrations (prompts authored here, generated by client in Nano Banana)
- Premium stock photography for v1 launch, swapped for real shoot photos pre-launch
- DNS cutover from Wix → Vercel

**Out of scope (v1 non-goals):**
- Patient portal / login
- Online insurance verification / eligibility check
- Blog / long-form articles (skipped — empty blog is worse than no blog)
- Multilingual (English only)
- Online application tracking for careers (form → email only)
- Booking / scheduling tool
- Live chat
- Custom CMS (MDX files in the repo; Claude edits content)
- Analytics beyond Vercel Analytics + Speed Insights

## 4. Architecture

**Stack:**
- **Next.js 15** (App Router) — matches the AETARS ecosystem
- **Vercel Pro** hosting (already paid for)
- **Tailwind CSS** for styling + design tokens
- **shadcn/ui** for accessible base components (buttons, dialogs, accordions, forms)
- **Framer Motion** for subtle scroll animations and page transitions
- **MDX** files under `/content` for page copy (Claude edits; no CMS in v1)
- **Resend** for form submission email delivery (free tier: 100 emails/day, sufficient for LCO volume)
- **Leaflet** with OpenStreetMap tiles for the service-area map (free, no API key)
- **Vercel Analytics + Speed Insights** — free on Pro plan

**Folder layout:**
```
/app              → Next.js routes (one folder per URL)
/components       → UI components (Button, Card, Nav, Footer, etc.)
/content          → MDX source for pages (services/*, faq, etc.)
/lib              → utilities (form handlers, email helpers)
/public/images    → static assets — photos, illustrations, icons
/styles           → Tailwind config + global CSS
```

**No database in v1.** Form submissions email directly to intake. If a referral-tracking database is added later, it uses Supabase (same as AETARS).

**Hosting:** Vercel Pro, auto-deploy from GitHub. Preview deploys for every PR. Production domain `mylifecareoptions.com` (DNS cutover from Wix at launch).

## 6. Design system

### Logo

**Icon mark:** rounded navy (`#0F2B47`) square, cream (`#FDEEDD`) house silhouette with pitched roof, care-blue (`#5A8BB8`) heart centered in the house. Flat, no 3D, no border ring, no medical cross. Final icon generated and approved 2026-04-17 (Nano Banana, `Prompt A` — edit mode).

**Wordmark:** typeset in code alongside the icon. "Lifecare Options" in Playfair Display Medium (navy) on top; "HOME HEALTH" in Inter, all caps, wide letter-spacing, slate-gray (`#6B7D92`) below.

### Color palette

| Role | Name | Hex |
|---|---|---|
| Primary text / headlines | Navy | `#0F2B47` |
| Primary CTA / links | Care Blue | `#5A8BB8` |
| Warmth / featured cards | Peach Cream | `#FDEEDD` |
| Section backgrounds | Mist | `#F7FAFC` |
| Default background | White | `#FFFFFF` |
| Body text secondary | Slate | `#6B7D92` |
| Success / certified badges | Success Green | `#2D6A4F` |
| Form errors | Alert Red | `#C0392B` |
| Borders / dividers | Borderline | `#E4ECF3` |

### Typography

- **Headlines:** Playfair Display (Medium / 500), via Google Fonts. H1 48px desktop / 36px mobile; H2 32px; H3 20px.
- **Body + UI:** Inter, via Google Fonts. Body 17px, 1.65 line-height. Caption 13px.
- No other fonts. No script / cursive anywhere.

### Component vocabulary

- **Buttons** — 3 variants: Primary (filled care-blue, pill), Secondary (outlined navy, pill), Tertiary (text link, care-blue).
- **Cards** — 3 variants: Peach Cream (featured), Mist (standard grid), White+border (dense grid).
- **Trust badges** — success-green pill: `✓ Medicare-certified`, `✓ CHAP-accredited`, `✓ Serving Katy since 2008`, `✓ 24/7 on-call`.
- **Stat tiles** — large Playfair numeral + small Inter label (used on Referral Sources page: `2 hr`, `48 hr`, `24/7`).
- **Spacing** — 4px base grid. Section padding 96px top/bottom desktop, 56px mobile. Card internal padding 24px.

### FAQ
- Accordion of 15–25 Q&As. SEO-optimized. Links into relevant service pages.

### Careers
- Header + "We're hiring" grid (RN · LVN · HHA · Caregiver) + benefits strip + application form. If LCO uses Indeed, link out.

### Contact
- Phone, fax, address, hours, embedded map, simple inquiry form. Separate from the Request Care form — this is for non-clinical questions.

### Request Care form
- Multi-step: (1) patient info, (2) insurance, (3) urgency, (4) contact info. Submissions go to intake via Resend. Confirmation page + email receipt.

## 12. Principles / guardrails

- **YAGNI.** No patient portal, no insurance verifier, no blog, no multilingual in v1. All defensible Phase 2 additions if requested later.
- **Real content over features.** Phase 4's content swap is the most important phase. A beautiful empty shell fails; a pretty site with real photos, real bios, real testimonials wins.
- **Accessibility is not optional.** WCAG 2.1 AA minimum; color contrast, keyboard nav, semantic HTML, `alt` text on every image.
- **Performance is a feature.** Images auto-optimized via Next.js Image; fonts self-hosted or `font-display: swap`; Core Web Vitals monitored via Vercel.
- **SEO basics, not SEO theater.** Real semantic HTML, meta descriptions per page, sitemap, Open Graph tags. No keyword stuffing, no doorway pages.
- **No dark patterns.** Primary CTAs are honest requests for contact, never disguised signups or fake urgency.
